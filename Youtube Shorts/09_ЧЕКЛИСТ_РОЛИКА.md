# 09. ЧЕКЛИСТ РОЛИКА

Держи открытым во время монтажа. **Если хоть один пункт не отмечен — ролик не публикуется.**

---

## 🎬 Хук (0:00–0:02)

- [ ] **1.** В первом кадре катастрофа уже идёт — не подводка, не логотип, не «в этом видео»
- [ ] **2.** В первом кадре есть движение (анимация или Ken Burns). Статика на старте = пролистали
- [ ] **3.** Голос звучит с 0:00, без музыкальной заставки перед ним
- [ ] **4.** **Ролик понятен без звука** — включи беззвучный режим и посмотри первые 3 секунды

## 📝 Сценарий

- [ ] **5.** 110–130 слов, длительность 40–55 секунд
- [ ] **6.** Есть все пять блоков: хук → ставка → эскалация → кульминация → петля
- [ ] **7.** В эскалации есть минимум **два бытовых конкретных образа** (заправка, холодильник, водонапорная башня), а не только абстракции
- [ ] **8.** **Петля замыкается на хук** — при автоповторе ролик читается бесшовно
- [ ] **9.** В финале НЕТ «comment below» и «subscribe» — они режут удержание

## 🖼 Визуал

- [ ] **10.** 8–12 кадров, ни один не висит дольше 5 секунд
- [ ] **11.** **Неровный ритм**: чередование примерно 2 / 2 / 4 / 1.5 сек. Не все кадры одной длины
- [ ] **12.** Самый сильный кадр стоит на **кульминации (≈0:35–0:50)**, а не в начале
- [ ] **13.** Соблюдён стиль-код: одна палитра, один источник света, дымка во всех кадрах
- [ ] **14.** **Смешанные источники:** есть хотя бы 2 кадра не из нейросети (NASA / сток)
- [ ] **15.** Переходы — только резкая склейка (максимум одно затемнение перед кульминацией)

## 🔤 Субтитры

- [ ] **16.** 2–4 слова на экране за раз, не длинные строки
- [ ] **17.** Текст выше нижней трети — её закрывает интерфейс YouTube
- [ ] **18.** Авто-субтитры **вычитаны руками**, ошибок распознавания нет
- [ ] **19.** Ключевые слова покрашены в оранжевый `#FF6B1A`, по одному слову на фразу

## 🔊 Звук

- [ ] **20.** Голос заметно громче музыки (гул на 15–20%)
- [ ] **21.** Есть **пауза-тишина** перед финальной фразой
- [ ] **22.** Музыка и эффекты **только из аудиотеки YouTube Studio**

## 📤 Публикация

- [ ] **23.** Экспорт 1080×1920, 30 fps
- [ ] **24.** Заголовок до 60 символов, есть обещание масштаба
- [ ] **25.** В описании строка `Hypothetical scenario based on real science. This is not a prediction of current events.`
- [ ] **26.** 3–5 хэштегов, не больше
- [ ] **27.** ⚠️ **Отмечен синтетический / изменённый контент** в разделе «Детали»
- [ ] **28.** Время публикации по файлу 06 (или поставлена отложенная публикация)
- [ ] **29.** Подрубрика соответствует дню недели (ротация из файла 06)
- [ ] **30.** Сразу после публикации написан закреплённый комментарий

---

## Финальный тест перед кнопкой «Опубликовать»

Посмотри свой ролик **без звука, на телефоне, один раз, не останавливая**.

Задай себе три вопроса:
1. Остановил бы палец на первом кадре, если бы это был чужой ролик?
2. Понятно, что происходит, без озвучки?
3. Захотелось пересмотреть с начала?

**Три «да» — публикуй. Хотя бы одно «нет» — чини хук.**
