# Ant World

Детерминированная воксельная симуляция колонии на numpy. Состояние живёт в массивах,
объектов-агентов не существует, ядро гоняется headless.

**[WORLD_RULES.md](WORLD_RULES.md) — источник истины.** Физика мира, порядок тика,
правила движения, контракт детерминизма и калибровка описаны там. Код не имеет права
расходиться с документом: расходится — либо правится код, либо сначала правится документ.

## Что это за мир

Воксельный параллелепипед 200×200×32, замкнутый со всех сторон («купол»): границы —
сплошной камень, поэтому проверок выхода за край нет нигде. В мире есть равнины, горы
с непрогрызаемыми каменными вершинами и река, которая непроходима.

Агент занимает один воксель, в вокселе не может быть двоих. Он лазает по поверхностям
как муравей — по стене, потолку, своду туннеля; гравитации и падения нет. Ходьба следует
за рельефом: ступенька в один воксель берётся тем же шагом, стена и обрыв в два вокселя
остаются границами.

Еда — двумерное поле на освещённой поверхности. Под землёй безопасно и голодно: это
главный компромисс мира.

У агента 12 сенсорных входов и две головы решения — движение (стоять + 6 направлений) и
действие (ничего / есть / копать). Геном — две матрицы весов, наследуется с гауссовым
шумом. Размножение автоматическое по порогу энергии.

## Быстрый старт

```bash
pip install -e ".[dev]"
pytest                       # 68 тестов, около 5 секунд
pytest -m slow               # полный масштаб: детерминизм на 10000 тиков, ~50 с
python -m antworld.bench     # тиков/сек
```

Прогон с записью и просмотр:

```python
from antworld.config import Config
from antworld import record

record.record_run(Config(), seed=1, ticks=6000, path="run.npz", every=30)
```

```bash
python viewer/pygame_viewer.py run.npz      # проигрывание записи
python viewer/pygame_viewer.py --live       # живой прогон
python viewer/build_web.py run.npz out.html # просмотрщик в браузере
```

## Модули

| Файл | Отвечает за |
|---|---|
| `antworld/config.py` | все числа физики и хеш конфигурации |
| `antworld/rng.py` | три потока PCG64, тай-брейки через splitmix64, побитовый хеш состояния |
| `antworld/voxel.py` | генерация мира, материалы, поверхность, копание, опора |
| `antworld/food.py` | поле еды и логистический рост |
| `antworld/agents.py` | состояние агентов как SoA, аллокация слотов, occupancy |
| `antworld/brain.py` | сенсоры, две головы, наследование генома |
| `antworld/movement.py` | конкуренция за клетку, состязание сил, толкание, ступеньки |
| `antworld/world.py` | девять фаз тика в документированном порядке |
| `antworld/events.py` | лог событий |
| `antworld/persist.py` | сохранение и загрузка состояния |
| `antworld/record.py` | запись прогона для просмотрщиков |
| `antworld/bench.py` | бенчмарк тиков/сек |

## Скорость

Полный мир 200×200×32, один прогон на одном ядре:

| Основателей | Популяция | Тиков/с | Агенто-тиков/с | мс/тик |
|---|---|---|---|---|
| 1 000 | 2 802 | 441 | 571 602 | 2.27 |
| 5 000 | 2 160 | 253 | 978 544 | 3.96 |
| 20 000 | 5 003 | 79 | 1 285 739 | 12.60 |

Лог событий на скорость практически не влияет, но выключается флагом
`World(cfg, seed, log_events=False)`.

## Детерминизм

Один сид плюс один `Config` дают побитово одинаковую последовательность состояний.
Проверяется на 10 000 тиков сравнением хеша всех массивов. RNG в цикле тиков расходуется
только на мутацию генома; все ничьи решаются детерминированным хешем, а не случайностью.
Состояние генератора входит в снапшот, поэтому `save → load → N тиков` даёт ровно то же,
что `N тиков` подряд.

## Что осталось за пределами первой вехи

Феромоны и осязание соседей, течение воды при прокопе к реке, строительство (отдельный
материал под постройки агентов), цепочки толчков, гравитация. Каждое из этого — изменение
`WORLD_RULES.md`, а не тихая правка кода.
