# İmpostor — söz oyunu 🕵️

Игра «Imposter» для iPhone на азербайджанском языке. Это PWA: открывается в Safari и устанавливается на экран «Домой» как обычное приложение. Работает без интернета, App Store и Mac не нужны.

## Что внутри

- **Классический режим**: все видят секретное слово, импостор видит «Sən impostorsan!».
- **💡 Подсказка (ipucu) для импостора**: включается переключателем перед игрой. Подсказка — это *дальняя* ассоциация, а не синоним (например, «Futbol» → «Yaşıl», «Həkim» → «Ağ»), так что слово по ней сразу не угадать.
- **Режим Undercover**: импостор получает похожее, но другое слово и не знает, что он импостор.
- **16 категорий, 426 слов**. Можно выбрать любые категории или «Hamısını seç» (все).
- **Игроки**: от 3 до 20, у каждого своё имя (имена запоминаются).
- **Количество импосторов** задаётся перед игрой (до ⌊(игроки−1)/2⌋).
- **Каждый раунд** заново и случайно выбираются импосторы, слово и порядок обсуждения (`crypto.getRandomValues` + Фишер–Йетс). Тот, кто начинал в прошлом раунде, первым не будет. Импостор первым не говорит (это можно отключить).
- Слова не повторяются, пока не закончатся все слова в выбранных категориях.
- **Таймер обсуждения** со звуковым сигналом; экран не гаснет, пока идёт отсчёт.
- **Тайное голосование** в приложении (телефон передаётся по кругу), подсчёт голосов, при ничьей никто не выбывает.
- **Таблица очков** между раундами и «последний шанс»: пойманный импостор может угадать слово.
- Кнопка «Sözümü unutdum», чтобы ещё раз посмотреть свою карточку.
- Если закрыть приложение, раунд сохранится. При повторном открытии карточки всегда скрыты.

## Как поставить на iPhone

1. Опубликуйте папку `imposter/` по HTTPS (варианты ниже).
2. Откройте ссылку в **Safari** на iPhone.
3. Нажмите **Поделиться ⬆︎**, затем **«На экран «Домой»» / Add to Home Screen**.
4. Запускайте с иконки «İmpostor»: приложение откроется на весь экран и будет работать офлайн.

### Где опубликовать

- **GitHub Pages**: workflow `.github/workflows/pages.yml` публикует `imposter/` при каждом пуше в `main`. Один раз включите *Settings → Pages → Source: GitHub Actions*. Для **приватного** репозитория Pages работает только на платном тарифе GitHub. Тогда либо сделайте репозиторий публичным, либо задайте переменную `DEPLOY_PAGES=true`.
- **Netlify / Vercel / Cloudflare Pages** (бесплатно, работают и с приватным репозиторием): подключите репозиторий и укажите папку публикации `imposter`. Сборка не нужна.

## Разработка

Сборки нет: чистые HTML/CSS/JS-модули.

```bash
npx http-server imposter -p 8080      # локальный сервер
npm test                              # unit-тесты логики и проверка словаря
node tests/e2e.mjs [папка_скриншотов] # полный сценарий в Chromium (нужен Playwright)
node tools/make-icons.mjs             # пересобрать PNG-иконки из icons/icon.svg
```

| Файл | Что там |
|---|---|
| `imposter/js/words.js` | Категории и слова: `[слово, подсказка, слово для undercover]` |
| `imposter/js/game.js` | Логика: случайность, импосторы, порядок, выбор слова, голоса, очки |
| `imposter/js/app.js` | Экраны и интерфейс |
| `imposter/css/style.css` | Стили |
| `imposter/sw.js` | Офлайн-кэш. **Увеличивайте `VERSION` при каждом изменении файлов**, иначе на телефонах останется старая версия |

### Как добавить слова

Добавьте строку в нужную категорию в `words.js`:

```js
['Pinqvin', 'Soyuq', 'Suiti'],
//  слово    подсказка  похожее слово (undercover)
```

Подсказка должна быть дальней ассоциацией: не синонимом, не частью предмета и не другим словом из той же категории. `npm test` проверяет это автоматически.
